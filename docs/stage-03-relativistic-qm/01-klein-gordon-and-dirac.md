# Klein–Gordon 方程与 Dirac 方程：相对论量子力学的尝试及其失败

> 路线图位置：第 3 阶段（经典场论 + 相对论量子力学，过渡桥梁）
> 前置知识：量子力学（薛定谔方程、概率流、算符）、狭义相对论（四维矢量、$E^2 = p^2 + m^2$）。
> 学习目标：亲手推出两个方程，理解它们各自的困难（负能量、负概率、粒子数可变），从而明白**为什么 QFT 必然存在**——这是整个第 4 阶段的入场动机。

---

## 1. 一句话总结

**把薛定谔方程"相对论化"的两次尝试——Klein–Gordon 方程和 Dirac 方程——作为单粒子量子力学都失败了：负能量解无法排除，KG 方程连正定的概率密度都给不出，而相对论本身就强迫粒子数可变。正确的解读是：它们不是单粒子的波动方程，而是经典场的运动方程；把场量子化，负能量解变成反粒子，一切自洽——这就是量子场论。**

## 2. 出发点：薛定谔方程哪里不相对论

自由粒子的薛定谔方程

$$i\frac{\partial \psi}{\partial t} = -\frac{1}{2m}\nabla^2 \psi$$

来自非相对论色散关系 $E = p^2/2m$，做替换

$$E \to i\partial_t, \qquad \vec p \to -i\nabla$$

就得到它。问题一目了然：

- **时空地位不对称**：对时间一阶导数、对空间二阶导数。狭义相对论要求 $t$ 与 $\vec x$ 平权（洛伦兹变换把它们混合），这个方程明显做不到。
- **色散关系不对**：相对论的质能关系是

$$E^2 = \vec p^{\,2} + m^2$$

（已取 $c=1$），而不是 $E = p^2/2m$。

所以任务很朴素：**从 $E^2 = \vec p^{\,2} + m^2$ 出发，用同样的替换规则，造一个相对论协变的量子方程。** 两条路——直接开方（KG）和聪明地开方（Dirac）——都有麻烦。

<details markdown="1"><summary>补充说明：自然单位制</summary>

本文设 $\hbar = c = 1$。这样能量、动量、质量同量纲（都用 eV 之类量度），长度和时间同量纲。恢复常数的窍门：康普顿波长 $\hbar/mc$、静能 $mc^2$ 是最常出现的组合。比如"$E^2 = p^2 + m^2$"恢复后是 $E^2 = p^2c^2 + m^2c^4$。

</details>

## 3. Klein–Gordon 方程

### 3.1 推导

直接把替换规则用于 $E^2 = \vec p^{\,2} + m^2$：

$$(i\partial_t)^2 \phi = (-i\nabla)^2 \phi + m^2 \phi,$$

即

$$\boxed{\left(\Box + m^2\right)\phi = 0}, \qquad \Box \equiv \partial_t^2 - \nabla^2 = \partial_\mu\partial^\mu.$$

$\Box$ 是洛伦兹不变的微分算符，所以方程协变性完美。试平面波解 $\phi = e^{-iEt + i\vec p\cdot\vec x}$，代入得 $E^2 = \vec p^{\,2} + m^2$——色散关系对了。历史上 Schrödinger 本人最先写下这个方程，后来由 Klein、Gordon 等人重新发现。

### 3.2 困难一：负能量解

$E^2 = \vec p^{\,2} + m^2$ 有两个分支：

$$E = \pm\,\omega_p, \qquad \omega_p \equiv \sqrt{\vec p^{\,2} + m^2} > 0.$$

$E = -\omega_p$ 的解与正能解一样合法。这很要命：

- 能谱**无下界**。一个与任何东西耦合的系统会不断向 $E \to -\infty$ 的态跃迁、释放无穷能量——没有稳定的世界。
- 非相对论里我们也只取 $E = +p^2/2m$，但那时色散关系本身就只有一个分支，没得选；相对论里两个分支是方程强制的。

你也许想说"扔掉负能解不就行了"——不行。只留正能解，波函数集合不完备（傅里叶展开少了一半基矢）；而且相互作用会把正能态和负能态混起来（Klein 佯谬：足够强的势垒前，粒子会以负能态"隧穿"过去，反射率大于 1）。

### 3.3 困难二：没有正定的概率密度

薛定谔方程有守恒流，$\rho = |\psi|^2 \geq 0$ 是概率密度，这是单粒子量子力学的命根子。KG 方程也有守恒流：用 $\phi^*$ 乘 KG 方程减去其复共轭，整理得

$$j^\mu = i\left(\phi^*\,\partial^\mu\phi - \phi\,\partial^\mu\phi^*\right), \qquad \partial_\mu j^\mu = 0.$$

但 $\rho = j^0 = i(\phi^*\partial_t\phi - \phi\partial_t\phi^*)$ 对平面波正比于 $E$——**负能解给出负的"概率密度"**。负概率没有意义。

这个困难是结构性的：KG 方程对时间是二阶的，初值问题要同时给定 $\phi$ 和 $\partial_t\phi$，两个函数的自由度注定了 $j^0$ 可正可负。单粒子概率解释在数学上被堵死了。

## 4. Dirac 方程

### 4.1 Dirac 的思路：时间和空间都只要一阶

Dirac 诊断：负概率的病根是时间的二阶导数。要 $\rho = \psi^\dagger\psi \geq 0$，方程必须对 $t$ 一阶（像薛定谔方程）；要洛伦兹协变，对 $\vec x$ 也得是一阶。于是他假设

$$i\partial_t\psi = \big(-i\,\alpha_i\partial_i + \beta m\big)\psi \equiv H\psi,$$

其中 $\alpha_i, \beta$ 是待定常数（不能是普通数，否则配不出 $E^2 = p^2 + m^2$）。

**要求**：两边再作用一次 $i\partial_t$ 应回到 KG（即每个分量满足正确的色散关系）。平方展开后交叉项必须消掉，这要求

$$\{\alpha_i, \alpha_j\} = 2\delta_{ij}, \qquad \{\alpha_i, \beta\} = 0, \qquad \beta^2 = 1.$$

普通数做不到两两反对易，但**矩阵**可以。满足这组关系的最小矩阵是 $4\times 4$。所以 $\psi$ 不是复数场，而是四分量对象——**旋量（spinor）**。

### 4.2 协变形式与 Clifford 代数

定义 $\gamma^0 = \beta$，$\gamma^i = \beta\alpha_i$，方程写成

$$\boxed{\left(i\gamma^\mu\partial_\mu - m\right)\psi = 0}$$

反对易关系紧凑地写成 **Clifford 代数**

$$\{\gamma^\mu, \gamma^\nu\} = 2\eta^{\mu\nu}, \qquad \eta = \mathrm{diag}(+1,-1,-1,-1).$$

一个常用表示（Dirac 基）：

$$\gamma^0 = \begin{pmatrix} I & 0 \\ 0 & -I \end{pmatrix}, \qquad
\gamma^i = \begin{pmatrix} 0 & \sigma^i \\ -\sigma^i & 0 \end{pmatrix},$$

其中 $\sigma^i$ 是泡利矩阵（SU(2) 那篇里的老朋友——这不是巧合，见第 6 节）。

### 4.3 修好了什么，没修好什么

**修好的**：定义共轭旋量 $\bar\psi = \psi^\dagger\gamma^0$，则

$$j^\mu = \bar\psi\gamma^\mu\psi, \qquad \partial_\mu j^\mu = 0,$$

且 $\rho = j^0 = \psi^\dagger\psi \geq 0$。**概率密度正定**——Dirac 的原始目标达成。

**没修好的**：负能量解还在。平面波解同样分两支：

$$\psi = u(p)\,e^{-ip\cdot x} \;\;(E>0), \qquad \psi = v(p)\,e^{+ip\cdot x} \;\;(E<0),$$

四分量的来源正是"自旋上/下 × 正能/负能" $= 2\times 2$。能谱依然无下界，稳定性问题原样存在。

### 4.4 Dirac 海：一个漂亮但救不了场的补丁

Dirac 的补救（空穴理论）：费米子服从泡利不相容原理，假设真空是**所有负能态都被填满**的"海"。海是惰性的、观测不到；从海里敲出一个电子（负能 → 正能）留下的"空穴"，表现得像一个**带正电、正能量的粒子**。

这个疯狂的想法预言了**正电子**，1932 年被 Anderson 在云室中发现——理论物理史上最著名的预言之一。加上 Dirac 方程自动给出自旋 1/2、正确的氢原子精细结构和电子 $g=2$，它作为"尝试"其实辉煌得过分。

但空穴理论有三个软肋：

1. **只对费米子有效**。KG 方程描述玻色子，没有泡利原理，负能海填不住——玻色子的负能量问题原封不动。
2. **多粒子本质**。真空里躺着无穷多个粒子，这已经不是"单粒子量子力学"了，只是不敢承认。
3. 把空穴当真粒子处理，数学上别扭（要减掉无穷大背景电荷、能量）。

## 5. 更深的困难：相对论本身禁止"单粒子"

就算把上面所有技术问题都糊弄过去，还有一个原则性的墙：**相对论 + 量子力学 ⟹ 粒子数不守恒**。

**能量论证**：相对论里静能 $mc^2$ 也是能量。只要相互作用能量超过 $2mc^2$，真空里就可以凭空产生一对粒子–反粒子。高能物理里粒子数从来不是好量子数——$e^+e^- \to \mu^+\mu^-$ 连粒子种类都变了。

**局域化论证**（更定量）：想把一个粒子限制在尺度 $\Delta x$ 内，不确定性关系要求 $\Delta p \gtrsim 1/\Delta x$，从而 $\Delta E \gtrsim 1/\Delta x$。当 $\Delta x$ 小到粒子的**康普顿波长**

$$\lambda_C = \frac{\hbar}{mc}$$

时，$\Delta E \gtrsim mc^2$——不确定的能量已足够产生粒子对。"这一个粒子在哪"的问题在这个尺度以下失去意义：你面对的一团东西里粒子数都在涨落。对电子 $\lambda_C \approx 3.9\times10^{-13}\,\mathrm{m}$；这就是为什么非相对论量子力学在原子尺度（$10^{-10}\,\mathrm{m}$）完美，而在更高能量下必然失效。

**因果性论证**：用 KG 方程计算粒子从原点传播到类空点 $\vec x$ 的振幅，结果不是零而是 $\sim e^{-m|\vec x|}$ 的指数尾巴。单粒子图像里这意味着超光速传播、违反因果。QFT 里这将被治好：场算符在类空间隔下**对易子**严格为零，正能传播与负能传播在类空方向恰好相消——注意，能相消的前提恰恰是正负两个分支都存在，且都被当作产生/湮灭过程认真对待。

结论：**"单粒子相对论波函数"这个概念本身就是错的框架。** 两个方程的负能量解不是 bug，而是路标——它们指向反粒子和粒子数可变的理论。

## 6. 出路：把波函数降级为场

正确的重新解读只有一步，但观念上是一次革命：

> $\phi(x)$、$\psi(x)$ 不是"粒子在 $x$ 处的概率幅"，而是**定义在时空每一点上的动力学变量——场**。KG 和 Dirac 方程是这些经典场的运动方程（可以从拉氏量经欧拉–拉格朗日方程推出，见路线图第 3 阶段的场论部分）。然后对**场**做量子化：$\phi(x)$ 提升为算符。

量子化之后，一切归位：

- 平面波展开里的正频部分 $e^{-ipx}$ 配上**湮灭算符**（消灭一个粒子），负频部分 $e^{+ipx}$ 配上**产生算符**（产生一个**反粒子**，带正能、反号电荷）。负能量解消失了，换成反粒子登场。
- 粒子数可变是天生的：哈密顿量由产生/湮灭算符构成，粒子可以成对产生和湮灭。
- KG 的守恒流 $j^\mu$ 重新解释为**电荷流**（正比于粒子数减负反粒子数）——可正可负天经地义，电荷本来就有两种符号。
- 场 = 无穷多谐振子（每个动量模式一个），这正是量子力学里产生/湮灭算符那套代数的直接推广。

Dirac 海则可以退休了：正电子就是正电子，一个真实的粒子，不是"海里的洞"。（空穴图像作为直觉辅助仍有价值，半导体里的空穴就是它留在凝聚态里的后代。）

还有一个拓扑层面呼应第一篇笔记的彩蛋：旋量场 $\psi$ 是 Lorentz 群双重覆盖 $\mathrm{SL}(2,\mathbb C)$ 的表示——正如自旋 1/2 来自 SU(2) 双重覆盖 SO(3)。时空对称性的整体拓扑，再一次决定了物质的基本形态。

## 7. 小结

| | KG 方程 | Dirac 方程 |
|---|---|---|
| 构造 | $E^2=p^2+m^2$ 直接替换 | 时空一阶 + Clifford 代数 |
| 概率密度 | 不正定 ✗ | 正定 ✓ |
| 负能量解 | 有 ✗ | 有 ✗ |
| 描述对象 | 自旋 0（玻色子） | 自旋 1/2（费米子） |
| 作为单粒子理论 | 失败 | 失败（空穴理论只是补丁） |
| 正确身份 | 标量场的经典场方程 | 旋量场的经典场方程 |

- 两个方程本身都是对的——错的是"单粒子波函数"这个解释框架。
- 负能量解 = 反粒子的先声；粒子数可变是相对论量子理论的内在要求。
- 下一步（第 4 阶段）：经典场论形式化（拉氏量 → 欧拉–拉格朗日方程），然后正则量子化，把上面的图景变成能算东西的理论。

## 自检问题

**1.** 从 $E^2 = \vec p^{\,2} + m^2$ 出发推出 KG 方程，并验证 $\phi = e^{-iEt+i\vec p\cdot\vec x}$ 是解的条件。

<details markdown="1"><summary>点击显示答案</summary>

替换 $E \to i\partial_t$，$\vec p \to -i\nabla$，两边作用于 $\phi$：

$$(i\partial_t)^2\phi = (-i\nabla)^2\phi + m^2\phi \;\Longrightarrow\; (\partial_t^2 - \nabla^2 + m^2)\phi = 0,$$

即 $(\Box + m^2)\phi = 0$。代入平面波：$\partial_t^2$ 给出 $-E^2$，$-\nabla^2$ 给出 $+\vec p^{\,2}$，故

$$-E^2 + \vec p^{\,2} + m^2 = 0 \;\Longleftrightarrow\; E^2 = \vec p^{\,2} + m^2,$$

即 $E = \pm\sqrt{\vec p^{\,2}+m^2}$ 时平面波是解。注意推导里替换规则作用在 $E^2$ 上，所以正负两个分支自动都在。

</details>

**2.** 证明 KG 流 $j^\mu = i(\phi^*\partial^\mu\phi - \phi\partial^\mu\phi^*)$ 守恒，并说明它为什么不能解释为概率流。

<details markdown="1"><summary>点击显示答案</summary>

**守恒**：对 $j^\mu$ 取散度，

$$\partial_\mu j^\mu = i\left(\partial_\mu\phi^*\,\partial^\mu\phi + \phi^*\Box\phi - \partial_\mu\phi\,\partial^\mu\phi^* - \phi\,\Box\phi^*\right) = i\left(\phi^*\Box\phi - \phi\,\Box\phi^*\right).$$

由 KG 方程 $\Box\phi = -m^2\phi$，$\Box\phi^* = -m^2\phi^*$，代入得 $\partial_\mu j^\mu = i(-m^2\phi^*\phi + m^2\phi\phi^*) = 0$。

**不能当概率流**：对平面波 $j^0 \propto E$，而 $E$ 可正可负，所以 $j^0$ 不正定；概率密度必须非负。数学根源是方程对时间二阶，初值含 $\phi$ 与 $\partial_t\phi$ 两份独立数据，$j^0$ 没有定号。QFT 里它获得合法身份：电荷密度（粒子减反粒子）。

</details>

**3.** 用 $(i\gamma^\mu\partial_\mu + m)$ 左乘 Dirac 方程，验证每个旋量分量都满足 KG 方程，并由此推出 Clifford 关系。

<details markdown="1"><summary>点击显示答案</summary>

$$(i\gamma^\mu\partial_\mu + m)(i\gamma^\nu\partial_\nu - m)\psi = -\left(\gamma^\mu\gamma^\nu\partial_\mu\partial_\nu + m^2\right)\psi = 0.$$

$\partial_\mu\partial_\nu$ 对 $\mu\leftrightarrow\nu$ 对称，所以只有 $\gamma^\mu\gamma^\nu$ 的对称部分有贡献：

$$\gamma^\mu\gamma^\nu\,\partial_\mu\partial_\nu = \tfrac12\{\gamma^\mu,\gamma^\nu\}\,\partial_\mu\partial_\nu.$$

要使它等于 $\Box = \eta^{\mu\nu}\partial_\mu\partial_\nu$（从而得到 $(\Box + m^2)\psi = 0$），当且仅当

$$\{\gamma^\mu, \gamma^\nu\} = 2\eta^{\mu\nu}.$$

物理含义值得记住：Dirac 方程是 KG 方程的"平方根"——每个旋量分量都满足正确的相对论色散关系，而 $\gamma$ 矩阵是为了开方而付出的代价（也是自旋的来源）。

</details>

**4.** 为什么说康普顿波长 $\lambda_C = \hbar/mc$ 是单粒子量子力学失效的尺度？

<details markdown="1"><summary>点击显示答案</summary>

把粒子局域到 $\Delta x$，不确定性原理强制动量不确定度 $\Delta p \gtrsim \hbar/\Delta x$，能量不确定度 $\Delta E \gtrsim \hbar c/\Delta x$（相对论性粒子 $E \approx pc$）。当 $\Delta x \lesssim \lambda_C = \hbar/mc$ 时，

$$\Delta E \gtrsim mc^2,$$

能量涨落达到静能量级，足以从真空产生粒子–反粒子对。此时"系统里有几个粒子"本身不再确定，单粒子波函数（及其概率解释）失去意义。换句话说：相对论量子力学里"一个粒子的位置"只在比 $\lambda_C$ 粗的尺度上有意义——这也是为什么 QFT 里基本对象是场（每一点的算符）而非粒子的位置波函数。

</details>

**5.** Dirac 海为什么救不了 Klein–Gordon 方程？

<details markdown="1"><summary>点击显示答案</summary>

空穴理论的基石是**泡利不相容原理**：负能态每个只能填一个粒子，填满后形成惰性背景，正能粒子无法再跃迁下去（态被占满），稳定性得以保证。

KG 方程描述的是**自旋 0 的玻色子**（标量场）。玻色子不受泡利原理限制：一个负能态可以堆积任意多个粒子，"海"永远填不满，正能粒子照样可以无限跃迁到负能态并继续往里掉。所以对玻色子不存在稳定的 Dirac 海，负能量问题原样保留。

这说明空穴理论不是普适答案，只是碰巧对费米子有效的临时方案。普适的解决方案只有一个：量子化场，把负频解重新解释为反粒子的产生算符——它对玻色子、费米子一视同仁。

</details>
