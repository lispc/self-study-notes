## 1. 一句话总结

**拓扑序是 Landau 对称性破缺范式之外的第二种"序"：分数量子霍尔态、自旋液体这些相没有可区别的对称性、没有局域序参量，却是不容混淆的不同相——文小刚的纲领把它们统一理解为"长程纠缠的不同模式"，可测量的信物是三件：拓扑基态简并（环面 $m$ 重、局域扰动拆不动）、任意子（分数统计的粒子化激发）、拓扑纠缠熵 $S = \alpha L - \gamma$（面积律里的常数修正，长程纠缠的指纹）。最小模型 toric code 一页解完所有信物：四重简并、$e$ 与 $m$ 互为半子、$\gamma = \ln 2$，且它就是 $\mathbb{Z}_2$ 规范理论的解禁闭相——拓扑序的场论语言是拓扑量子场论（Chern–Simons / $K$ 矩阵），与 QFT 书的规范结构直接接轨。第 12 章正文的能带拓扑重新归位为"短程纠缠 + 对称性保护"（SPT）的特例；弦网凝聚纲领则反过来问：光子和费米子本身会不会也是某种弦网液体里的涌现之物。**

## 2. 为什么需要新范式

第 7 章的 Landau 范式统治了相变理论七十年：相由对称性标记，相变由序参量描述。但 11s 的样本对此完全免疫：

- $\nu = 1/3$ 与 $\nu = 1/5$ 的两个液体**对称性完全相同**（无平移破缺、无自旋序、无任何局域序参量非零），却是不 能在不关能隙的情形下互相绝热连通的**不同相**（不同的任意子统计、不同的环面简并度）；
- 环面上的 $m$ 重简并**不是**对称性简并：没有任何局域算符能区分它，对称性破缺简并（第 7 章的 Ising 磁化方向）恰恰是局域序参量挑出来的——这里正相反，"序"住在**非局域**的地方。

文小刚（1989–90，从手征自旋液体与分数量子霍尔的研究中）给出的回答：**相的本质标签不是对称性，而是纠缠结构**——基态波函数里长程关联的"模式"。可严格化为两级分类：

- **短程纠缠（SRE）**：存在局域幺正（有限深度的局域电路）把基态变成直积态——纠缠可以被局域地"拆掉"。这类态**没有内禀拓扑序**，全部信息在局域性质里；若要求拆解过程尊重某对称性而拆不动，就是**SPT 态**（symmetry-protected topological）——第 12 章的 SSH、拓扑绝缘体全在此列：保护它们的是时间反演，拆掉对称性就能平庸化。
- **长程纠缠（LRE）**：不存在任何有限深度电路能拆到直积态——纠缠本身是物相性质。**内禀拓扑序 = LRE 态的等价类**。分数量子霍尔、toric code、$\mathbb{Z}_2$ 自旋液体住在这里。

（纠缠深度与第 20 章的面积律接得上：SRE 态的纠缠熵严格服从面积律且无常数修正；LRE 态在面积律上多出拓扑项——第 5 节。）

## 3. Toric code：一页解完三件信物

Kitaev（1997/2003）为拓扑量子计算发明的最小模型——正方格子边上放自旋 1/2，哈密顿量是**对易投影子的和**：

$$H = -J_e\sum_s A_s - J_m\sum_p B_p,\qquad A_s = \prod_{i\in star(s)}\sigma_x^i,\qquad B_p = \prod_{i\in\partial p}\sigma_z^i.$$

$A_s$ 是格点 $s$ 周围四条边上的 $\sigma_x$（星），$B_p$ 是格子 $p$ 四条边上的 $\sigma_z$（面）。**关键对易性**：任一星与任一面共享 0 或 2 条边，$\sigma_x\sigma_z\sigma_x = -\sigma_z$ 反号成对出现——$[A_s, B_p] = 0$。于是全部本征值 $\pm1$ 可同时指定，基态 $A_s = B_p = +1$。

**三件信物**（细节在自检问题 1–2）：

- **四重简并**（环面上）：$A_s = 1$ 把希尔伯特空间剪成"闭弦"子空间；环面两个非收缩环路各携带一个 $\mathbb{Z}_2$ 自由度，$B_p$ 约束不碰它们——基态 $2\times2 = 4$ 重（约束计数：$2^E \to$ 剪 $V-1$ 个星约束与 $P-1$ 个面约束，用欧拉公式 $V - E + P = 0$ 恰好剩 $2^2$）。
- **任意子**：违反 $A_s = -1$ 的格点上是 **$e$ 粒子**，违反 $B_p = -1$ 的面上是 **$m$ 粒子**（两者都是能量 $2J$ 的局域缺陷，间隙使它们在低温下稀少）。开弦算符（路上乘 $\sigma_z$）在端点制造一对 $e$；对偶路上乘 $\sigma_x$ 制造一对 $m$。
- **互半子统计**：两条弦算符穿过奇数次则反对易（每交一次贡献一个 $\sigma_x\sigma_z$ 反号），

$$W_e(\gamma)\,W_m(\gamma') = (-1)^{\gamma\cdot\gamma'}\,W_m(\gamma')\,W_e(\gamma)\qquad\Longrightarrow\qquad \theta_{e\times m}\ \text{互换相位} = \pi：$$

**$e$ 与 $m$ 各自是玻色子，但互相绕一圈各得相位 $-1$**（互半子）；复合 $\varepsilon = e\times m$ 因此是费米子（自绕相位 $= 1\times1\times(-1) = -1$）——同一格子上，玻色子的自旋 1/2"组装"出了费米子。分数统计第一次以中学代数的硬度出现。

**稳定性**（拓扑序的"鲁棒"二字的确切含义）：加任意局域扰动 $\delta H$，四重简并只在微扰阶 $(\delta/J)^L$（$L$ = 环面周长）下分裂——分裂需要虚过程绕环面一周，隧穿振幅随路径长度指数压低。**简并度在热力学极限下严格守恒**，这是拓扑量子计算（第 7 节）存信息的原理。

**身份认证**：toric code = $\mathbb{Z}_2$ 规范理论的解禁闭相（$e$ = 规范电荷，$m$ = 规范通量/vison，互半子正是电荷–通量的 Aharonov–Bohm 相位）——第 13 章顺嘴提过的"自旋液体里的规范结构"在此落地：**$\mathbb{Z}_2$ 自旋液体 = toric code 的自旋实现**（kagome/三角格子的理论候选，第 20 章的 DMRG 是甄别它的主力工具——三种内容在同一处会师）。

## 4. 拓扑纠缠熵：给纠缠照相

第 20 章：有能隙局域哈密顿量的基态服从**面积律** $S(A) \sim \alpha\,\lvert\partial A\rvert$。精细结构揭示：

$$\boxed{\;S(A) = \alpha\,\lvert\partial A\rvert - \gamma + o(1)\;},\qquad \gamma = \ln\mathcal D\ \ge\ 0,$$

$\mathcal D$ = 总量子维度（任意子量子维度的平方和开根，$\mathcal D = \sqrt{\sum_a d_a^2}$）。常数项 $-\gamma$ 是**长程纠缠的指纹**：SRE 态 $\gamma = 0$（$\mathcal D = 1$）；toric code 三个任意子 $d_e = d_m = d_\varepsilon = 1$，$\mathcal D = 2$，$\gamma = \ln 2$；Laughlin $\nu = 1/m$ 态 $\mathcal D = \sqrt m$，$\gamma = \tfrac12\ln m$。

**测量方案**（Kitaev–Preskill / Levin–Wen，2006）与**微观出处**都在自检问题 3：面积项来自边界附近的局域纠缠（随边界长度伸缩），拓扑项来自"跨越边界的闭弦/任意子回路的全局宇称"——对 toric code 的基态，区域边界处弦的绕行宇称处于两种可能的等权叠加，这份全局自由度的香农熵恰是 $\ln 2$。**面积项是局域物理（细节多多），$\gamma$ 是拓扑物理（普适）**——减法方案把前者消掉，只留后者。纠缠熵从第 20 章的"方法可行性量具"升职为"相的分类量具"。

## 5. 有效理论：$K$ 矩阵与 Chern–Simons

拓扑序的低能有效理论是**拓扑量子场论**——没有局域自由度、只有全局/拓扑响应的场论。阿贝尔霍尔态统一写成 **$K$ 矩阵**形式（$K$ 为整数对称矩阵，$t$ 为电荷矢量）：

$$\mathcal L = \frac{1}{4\pi}K_{IJ}\,\epsilon^{\mu\nu\lambda}a_{I\mu}\partial_\nu a_{J\lambda} - e\,t_I\,a_{I\mu}j^\mu,$$

三个可算量（自检问题 4）：

$$\nu = t^{\mathrm T}K^{-1}t,\qquad \theta_\ell = \pi\,\ell^{\mathrm T}K^{-1}\ell\ (\text{任意子 }\ell),\qquad \dim(\text{环面}) = \lvert\det K\rvert.$$

**统一账本**：Laughlin $\nu = 1/m$：$K = (m)$，$t = 1$ → $\nu = 1/m$ ✓、$\theta = \pi/m$ ✓（11s 的 ASW 结果）、简并 $m$ ✓（11s 的计数）——**第 5 节把 11s 的三件信物一次性复述**。toric code（无电荷输运的玻色拓扑序）：$K = \begin{pmatrix}0&2\\2&0\end{pmatrix}$，$t = 0$：$\ell = (1,0)$ 与 $(0,1)$ 各自 $\theta = 0$（玻色）、互相 $\theta_{\text{mutual}} = 2\pi\ell_1^{\mathrm T}K^{-1}\ell_2 = \pi$（互半子 ✓）、简并 $|\det K| = 4$ ✓——第 3 节的代数结论被场论重新发行。这套语言与 QFT 书的规范场章节直接衔接（Chern–Simons 作用量的规范不变性、大规范变换的配分约束——正是拓扑简并的场论来源）；非阿贝尔态（$\nu = 5/2$ 的 Moore–Read/Pfaffian）需要非阿贝尔 Chern–Simons，任意子"统计"从相位升级为矩阵。

## 6. 分类版图与弦网纲领

**两级四象限**（文小刚的相图语言）：

| | 无对称性要求 | 有对称性 $G$ |
|---|---|---|
| 短程纠缠 | 直积态（平庸） | **SPT 态**：SSH、拓扑绝缘体（第 12 章）、Haldane 链 |
| 长程纠缠 | **内禀拓扑序**：toric code、$\mathbb Z_2$ 自旋液体、$\nu=1/m$ | 对称富化拓扑序（SET）：对称性与任意子耦合（分数量子绝缘体等） |

判据一句话：**SPT 的边界可以有激发但不能有内禀体拓扑简并；内禀拓扑序去掉一切对称性也拆不掉**（$K$ 矩阵/任意子内容不依赖对称性）。第 12 章整篇的能带拓扑，在这个版图里是"第一行右格"的免费费米子特例——这既是让位，也是定位。

**弦网凝聚**（Levin–Wen 2005；Wen 2003 的量子序纲领）：toric code 的基态是"所有闭弦（$\sigma_x$ 方向的畴壁）等权叠加"——**闭弦的凝聚**。推广到任意"弦网"（分叉、带标签的字符串网络）的凝聚态， Levin–Wen 证明了可解模型的一揽子定理：

- 弦网的**涨落波** = 涌现的**规范玻色子**（$\mathbb Z_2$ 弦网给一个光子般的无质量玻色模式；$U(1)$ 弦网给麦克斯韦光子）；
- 开弦的**端点** = 任意子/费米子（端点的统计由弦的拓扑决定——toric code 的 $\varepsilon$ 费米子是第一例）。

文小刚把它推向纲领性的一问：**如果真空本身就是某种弦网凝聚态——光子是网的涨落、电子是开弦的端——规范相互作用与费米统计就都是"涌现"的**，如同声子与超流的相位之于晶体/液体。这是猜想性的物理（如何得到手征费米子与标准模型是其最难的部分），但它把"拓扑序"从凝聚态的分类学抬升为"物质与相互作用从何而来"的候选答案。诚实地说：这是本篇里最没有实验判决的一段，也是最辽阔的一段。

## 7. 拓扑量子计算：信物的用法

任意子统计可以当计算机用：非阿贝尔任意子的交换是**融合空间上的幺正矩阵**（而非相位），$n$ 个任意子的融合空间维数随 $n$ 增长（Ising 任意子 $\sigma\times\sigma = 1 + \psi$，$d_\sigma = \sqrt2$，$n$ 个 $\sigma$ 维数 $\sim 2^{n/2-1}$；斐波那契任意子 $\tau\times\tau = 1+\tau$，维数 $\sim\varphi^n$ 且编织普适）。把信息存在融合路径里，**编织 = 门，能隙 + 拓扑简并 = 免疫局域噪声**（第 3 节的 $(\delta/J)^L$ 稳定性就是保真度的来源）。候选实现：$\nu = 5/2$ 分数量子霍尔态（Ising 型）、分数量子反铁磁、以及最接近实验的**Majorana 零模**（拓扑超导线的端点 = Ising 任意子的固态替身——但 Ising 编织不普适，需配对辅助门）。拓扑量子计算是拓扑序三件信物的合订应用：简并存比特、编织做运算、能隙防出错。

## 小结

- 新范式：序 = 长程纠缠的模式；SRE（可拆）/LRE（不可拆）两级，对称性只是第二级里的修饰（SPT/SET）——第 12 章正文归位为 SPT 一支。
- Toric code：对易投影子一页解完——四重简并（拓扑性、指数稳定）、$e/m$ 互半子、$\varepsilon$ 费米子；= $\mathbb Z_2$ 规范理论解禁闭相 = $\mathbb Z_2$ 自旋液体。
- 拓扑纠缠熵 $S = \alpha L - \ln\mathcal D$：面积律上的拓扑指纹；toric code $\gamma = \ln 2$；Laughlin $\gamma = \tfrac12\ln m$。
- $K$ 矩阵：$\nu$、统计、$|\det K|$ 三个公式复述 11s 全部信物；场论形态是 Chern–Simons（与 QFT 书接轨）。
- 弦网凝聚：规范玻色子 = 网的涨落、费米子/任意子 = 弦端——"光与物质或为涌现"的纲领。
- 应用：拓扑量子计算（非阿贝尔编织）。

**(a)**：格点 $s$ 的星（触到 $s$ 的四条边）与格子 $p$ 的边界共享边的数目只能是 0、2（正方格子几何）。共享 0 条边：显然对易。共享 2 条边：$B_p$ 中两个 $\sigma_z$ 各与 $A_s$ 中一个 $\sigma_x$ 反对易，$(-1)^2 = +1$，整体对易 ✓。

**(b)**：边上共 $E$ 个自旋 → $2^E$ 维。约束 $A_s = 1$：$V$ 个星约束中 $\prod_s A_s = \prod_{\text{边}}(\sigma_x)^2 = 1$ 自动成立 → 独立约束 $V - 1$ 个，剩 $2^{E - V + 1}$。约束 $B_p = 1$：同理 $\prod_p B_p = 1$ → 独立 $P - 1$ 个。最终维数

$$2^{E-V+1-(P-1)} = 2^{E - V - P + 2} = 2^{2} = 4\qquad(\text{环面上 } V - E + P = 0).$$

**直观**：$A_s = 1$ 是"闭弦"条件（$\sigma_x$ 翻转的边构成无端点的串）；闭弦空间里只剩"沿环面两个不可收缩方向各绕不绕"两个 $\mathbb Z_2$ 比特，$B_p$ 约束不干涉这两个全局宇称——**基态 = 四种全局弦宇称的等权叠加**（这也直接给出第 4 节的 $\ln 2\times 2$ 结构）。

**(c)**：弦算符 $W_e(\gamma) = \prod_{i\in\gamma}\sigma_z^i$（直接格子上的路径）在其两个端点各违反一个 $A_s$（路径内部格点被翻转偶数次抵消）→ 端点即 $e$ 粒子。$W_m(\tilde\gamma) = \prod_{i\in\tilde\gamma}\sigma_x^i$（对偶路径）同理造 $m$。

- **各自玻色**：$W_e(\gamma)^2 = 1$：把一个 $e$ 绕自身路径走两圈等于恒等 → 自统计 $\theta_e = 0$；$m$ 同理。
- **互半子**：直接路径 $\gamma$ 与对偶路径 $\tilde\gamma$ 每交叉一次，$\sigma_z\sigma_x = -\sigma_x\sigma_z$ 贡献一个 $-1$：

$$W_e(\gamma)W_m(\tilde\gamma) = (-1)^{\gamma\cdot\tilde\gamma}W_m(\tilde\gamma)W_e(\gamma),$$

把 $e$ 绕 $m$ 一圈（交叉奇数次）得相位 $-1 = e^{i\pi}$ ✓。
- **$\varepsilon$ 费米**：复合粒子的自统计 = 自统计之积 × 互绕相位（绕复合体一圈 = 各自绕 + 交叉互绕）：$\theta_\varepsilon = 0 + 0 + \pi = \pi$ → 费米子 ✓。**玻色子格子上造出费米子**，这正是弦网纲领"费米统计可涌现"的最小实证。

</details>

**2.** 稳定性与拓扑简并的"拓扑"：证明任意局域扰动对四重简并的分裂至多 $O\big((\delta/J)^L\big)$（$L$ 为环面周长），并对比对称性破缺简并（第 7 章）在同样扰动下的行为——说明"拓扑序对杂质免疫"的机制。

<details markdown="1"><summary>点击显示答案</summary>

**机制**：四个基态 $|\varphi_{ab}\rangle$（$a, b \in \{0,1\}$ 为两个环向弦宇称）在一切**局域**算符 $\hat O_{\text{loc}}$ 下矩阵元完全相同：

$$\langle\varphi_{ab}\rvert\hat O_{\text{loc}}\lvert\varphi_{a'b'}\rangle = C_O\,\delta_{aa'}\delta_{bb'}.$$

（证明思路：局域算符改变弦位形只在一团有界区域内，四个全局宇称扇区在该区域外的波函数结构逐点相同；形式上用 $W_e, W_m$ 大回路的对易关系反推。）

**微扰论的后果**：一阶修正 $\langle\varphi\rvert\delta H\lvert\varphi'\rangle$ 对非对角元为零——简并在一阶下不动。把四个态连起来的最低阶过程是**绕环面一周的虚弦涨落**：其振幅 $\sim (\delta/J)^L$（微扰展开中每一步翻转一条边、代价 $\delta/J$，连接不同宇称扇区至少要翻转一条跨越整个环面的链）：

$$\Delta_{\text{split}} \sim J\Big(\frac{\delta}{J}\Big)^{L}.$$

$L\to\infty$（热力学极限）下分裂严格为零——**简并度是拓扑不变量**。

**与对称性简并的对比**：Ising 铁磁的两个磁化态由 $Z_2$ 对称性保护，但任何破坏对称性的局域场（杂质带来的局部偏好方向）在一阶微扰就把它们劈开，分裂 $O(\delta)$ 与尺寸无关。**区别的根源**：对称性简并的两个态可以被局域算符区分（局域磁化），拓扑简并的两个态不能——"保护"的不是抽象对称性，而是"没有任何局域手段够得着"这个信息论事实。这正是拓扑量子计算选它存比特的原因。

</details>

**3.** 拓扑纠缠熵：推导 toric code 基态的 $S(A) = \alpha\lvert\partial A\rvert - \ln 2$（$A$ 为单连通区域），并解释 Kitaev–Preskill 三分割减法如何把 $\alpha$ 消掉、只留 $\gamma = \ln 2$；推广到环面切出圆柱区域时的 $-2\ln 2$。

<details markdown="1"><summary>点击显示答案</summary>

**微观出处**：toric code 基态 = 闭弦等权叠加。把系统切成 $A$ 与 $\bar A$，数边界 $\partial A$ 上的自由度：每条被切开的边携带一个二值信息（弦是否由此穿越），$L$ 条边最多 $2^L$ 种边界位形。但闭弦必须**进出成对**——穿越边界的弦总数为**偶**：一条全局约束把边界位形空间削掉一个二值自由度：

$$S = (L - 1)\ln 2 = \underbrace{L\ln 2}_{\alpha L\ \text{（面积项，逐边贡献）}} - \ln 2\qquad\Longrightarrow\qquad \gamma = \ln 2 = \ln\mathcal D,\ \ \mathcal D = 2.$$

**Kitaev–Preskill 减法**：$\alpha$ 依赖微观细节（弦张力等），$\gamma$ 普适。取三块区域 $A_1A_2A_3$ 在一点相会，构造组合

$$\Gamma = S_1 + S_2 + S_3 - S_{12} - S_{23} - S_{31} + S_{123}.$$

每个边界段的 $\alpha$ 贡献出现正负各一次（逐段核对：内边界段在单项和组合项中恰好抵消）——**面积项全消**。剩余：七个区域的"边界拓扑"差别只有 $A_{123}$ 的整体边界是一条**闭合**曲线而各小块边界在其上开了分叉点——闭合边界携带 1 个全局弦配对（$-\gamma$ 一次），分叉组合不产生新的——净结果 $\Gamma = -\gamma = -\ln 2$。**减法把几何留给几何、把拓扑留给拓扑**。

**环面切圆柱**：圆柱区域有**两条**独立边界，各自携带一个 $\mathbb Z_2$ 配对（等价地：圆柱的两个环向割线各切一次全局弦回路）：

$$S_{\text{柱}} = \alpha\cdot(2L_{\text{周}}) - 2\ln 2 + (\text{连接修正 } o(1)),$$

每个独立非收缩割道贡献一个 $-\ln\mathcal D$——**纠缠熵读出流形的拓扑**（这正是它配当"序参量"的原因：响应的是相的拓扑内容而非几何）。

</details>

**4.** $K$ 矩阵三算：(a) 对 $K = (m)$、$t = 1$ 复述 11s 的三件信物；(b) 对 $K = \begin{pmatrix}0&2\\2&0\end{pmatrix}$、$t = 0$ 复述 toric code 的任意子内容；(c) 数值验证 $\nu = 2/5$ 可由 $K = \begin{pmatrix}3&2\\2&3\end{pmatrix}$、$t = (1,1)$ 描述，并给出其基本任意子的电荷与统计角。

<details markdown="1"><summary>点击显示答案</summary>

**(a)** Laughlin：$K^{-1} = (1/m)$：$\nu = 1\cdot\tfrac1m\cdot1 = 1/m$ ✓；任意子 $\ell = 1$：$\theta = \pi\cdot\tfrac1m$ ✓（ASW）；环面简并 $\lvert\det K\rvert = m$ ✓。

**(b)** toric code：$K^{-1} = \begin{pmatrix}0&\tfrac12\\\tfrac12&0\end{pmatrix}$。四个基本整数矢量：$\ell_e = (1,0)$、$\ell_m = (0,1)$：各自 $\theta = \pi\ell^{\mathrm T}K^{-1}\ell = 0$（玻色 ✓）；互绕 $2\pi\ell_e^{\mathrm T}K^{-1}\ell_m = 2\pi\cdot\tfrac12 = \pi$（互半子 ✓）；$\ell_\varepsilon = (1,1)$：$\theta = \pi(\tfrac12 + \tfrac12) = \pi$（费米 ✓）；$t = 0$ 一切激发不带电荷 ✓；简并 $\lvert\det\rvert = 4$ ✓。**三行代数复述第 3 节的整节**。

**(c)**：$\det K = 9 - 4 = 5$，$K^{-1} = \tfrac15\begin{pmatrix}3&-2\\-2&3\end{pmatrix}$：

$$\nu = t^{\mathrm T}K^{-1}t = \tfrac{1}{5}(3 - 2 - 2 + 3) = \frac{2}{5}\ ✓;\qquad \dim(\text{环面}) = 5.$$

基本任意子取 $\ell = (1,0)$：电荷 $q = e\,t^{\mathrm T}K^{-1}\ell = \tfrac{e}{5}(3 - 2) = \tfrac{e}{5}$；统计角 $\theta = \pi\tfrac{3}{5}$。核对复合费米子图像：$\nu = 2/5 = p/(2p+1)$、$p=2$，最小电荷单位 $e/5$ ✓。（层级态的 $K$ 矩阵构造：对角元 $2k+1$、非对角 $2k$ 的规则结构，把 Jain 序列整个装进对称矩阵的代数里。）

**方法论**：$K$ 矩阵把"猜波函数 + 数简并 + Berry 相位算统计"的体力活压缩成线性代数——**拓扑序的低能有效理论名副其实**：不理会微观，只对拓扑荷记账（与第 9 章 Landau–Ginzburg 之于对称性破缺的地位相同，只是"序参量"换成了 $K$）。

</details>

**5.** SPT 与内禀拓扑序的判别：证明 (a) 一维 AKLT/Haldane 链是 SRE（存在有限深度电路拆到直积态，若不要求保自旋平移与时间反演），但保对称性时拆不动（SPT）；(b) toric code 无论保不保对称性都拆不动（LRE）；(c) 由此说明两者的边界激发谁受对称性保护、谁是内禀的。

<details markdown="1"><summary>点击显示答案</summary>

**(a)**：AKLT 链 = 相邻自旋 1 投影到单态的 valence bond 固体。拆解电路：逐对应用局域幺正把单态"拉直"——有限深度（深度 $\sim$ 常数）的电路把 AKLT 变成直积态（每个格点剩一个 $S = 1/2$ 自由度配对的平庸形式）→ **SRE**。但任何尊重 $SO(3)$ 对称性的有限深度电路都做不到：如果做得到，链的三重态激发谱与边界 $S = 1/2$ 模（Haldane 链的标志）就无从谈起；严格论证用"奇偶二分 + 非平凡 SPT 不变量"（不可逆对称性纠缠结构）——**对称性是 SPT 的生命线**。

**(b)**：toric code 拆不动的反证：若有限深度电路 $U$（对称与否皆可）把基态变到直积态，则(a) 四重简并也随之平庸化（直积态在环面上只能 1 重）；(b) $e$、$m$ 任意子间的互半子统计是幺正等价不变量，而直积态的激发只有无统计的自由粒子——矛盾。任意子内容（长程纠缠的"模式"）是**内禀**的拓扑不变量，与对称性无关。

**(c)**：**边界**——SPT 的边界态（SSH 零模、TI 的 Dirac 锥、Haldane 链端点的 $S=1/2$）由体内对称性保护：破坏对称性即平庸化（第 12 章体-边对应的深层原因）。内禀拓扑序的边界载有**任意子流**（手征/非手征 Luttinger 边缘）且体简并与统计不依赖任何对称性——去掉所有对称性它依然是它。判据口诀：**能被对称性拆掉的叫 SPT，谁也拆不掉的叫拓扑序**。

</details>
