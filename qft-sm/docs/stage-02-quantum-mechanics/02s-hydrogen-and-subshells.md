# 补充材料：氢原子与电子亚层——$n$、$l$ 从哪来，周期表为什么长这样

> 路线图位置：第 2 阶段（量子力学）· 第 02 篇[角动量理论](02-angular-momentum.md)的补充材料
> 前置知识：第 02 篇（球谐函数 $Y_l^m$、好量子数、简并结构第 8 节）；本科量子力学的薛定谔方程与分离变量；多电子部分用到 Pauli 原理（其交换起源见凝聚态书[磁性](../../../condensed-matter/docs/07-magnetism.md)第 2 节，本篇只引用结论）。
> 学习目标：会从径向方程的束缚态边界条件推出主量子数 $n$、$n \ge l+1$ 与能级 $E_n = -13.6\,\text{eV}/n^2$；会说清三个量子数各自的"管辖范围"与每层简并的对称性来源；会用屏蔽与钻穿解释多电子原子的亚层能量次序（Madelung 规则）、4s 与 3d 之争、过渡金属组态与 Cr/Cu 例外；知道 s/p/d/f 名字的谱线来历。
>
> 记号约定：本篇保留 $\hbar$（与第 02 篇一致）。$Z$ 为核电荷数，玻尔半径 $a_0 = 4\pi\varepsilon_0\hbar^2/(m_e e^2) \approx 0.529$ Å，精细结构常数 $\alpha = e^2/(4\pi\varepsilon_0\hbar c) \approx 1/137$，均在文中出现处定义。

## 1. 一句话总结

**电子亚层是一套三人分工的记账系统：$l$ 与 $m_l$ 来自角向——旋转群的表示论（球谐函数，第 02 篇），$n$ 来自径向——束缚态波函数的归一化要求把级数解强行截断，$n = n_r + l + 1$；氢原子里能量只依赖 $n$（库仑势特有的隐藏对称性），但多电子原子中每个电子都被别人屏蔽，能量变成 $(n, l)$ 的函数——$l$ 小的轨道钻穿越深、感受到的有效电荷越大、能量越低，于是 4s 沉到 3d 之下，壳层内部裂出"亚层"次序，Madelung 规则排出元素周期表；Pauli 原理给每个亚层 $2(2l+1)$ 个座位。**

下面先把氢原子解掉（补上"会算氢原子"这块欠账），再做简并的对称学账本，最后讲多电子填充——那才是"亚层"概念真正发挥作用的地方。

## 2. 氢原子：三个量子数的分工

### 2.1 分离变量：角向自动解好

类氢原子哈密顿量（折合质量近似取 $m_e$，约定）：

$$H = -\frac{\hbar^2}{2m_e}\nabla^2 - \frac{Ze^2}{4\pi\varepsilon_0 r}.$$

库仑势是中心势，$[H, L^2] = [H, L_z] = 0$（第 02 篇第 4 节），所以解可以同时取 $L^2$、$L_z$ 的本征态：$\psi = R(r)\,Y_l^m(\theta,\phi)$，**角向部分一次性做完**——$l = 0, 1, 2, \dots$ 与 $m = -l, \dots, l$，全是第 02 篇的既有结果。剩下的径向方程对 $u(r) = rR(r)$ 最干净：

$$-\frac{\hbar^2}{2m_e}\frac{d^2u}{dr^2} + \left[\frac{l(l+1)\hbar^2}{2m_e r^2} - \frac{Ze^2}{4\pi\varepsilon_0 r}\right]u = E\,u.$$

物理图像：一维半直线上的运动，等效势 = 离心垒 $l(l+1)\hbar^2/2m_er^2$ + 库仑井。$l$ 越大，离心垒把波函数推得离核越远——这句图像后面解释"钻穿"时直接复用。

### 2.2 $n$ 的来历：归一化强行截断级数

束缚态 $E < 0$，记 $\kappa = \sqrt{-2m_eE}/\hbar$、$\rho = 2\kappa r$、无量纲常数 $\lambda \equiv Z/(\kappa a_0)$。两端渐近行为：$\rho \to 0$ 时离心垒主导，$u \sim \rho^{l+1}$；$\rho \to \infty$ 时 $u \sim e^{-\rho/2}$。代入

$$u(\rho) = \rho^{\,l+1}e^{-\rho/2}\,v(\rho),$$

得 $v$ 的方程（连带 Laguerre 型）：

$$\rho\,v'' + (2l + 2 - \rho)\,v' + (\lambda - l - 1)\,v = 0.$$

幂级数 $v = \sum_j a_j \rho^j$ 代入，得递推关系

$$\frac{a_{j+1}}{a_j} = \frac{j + l + 1 - \lambda}{(j+1)(j + 2l + 2)}.$$

**关键时刻**：若级数不终止，大 $j$ 处 $a_{j+1}/a_j \to 1/j$——这正是 $e^{+\rho}$ 的泰勒系数行为，$u \sim \rho^{l+1}e^{+\rho/2}$ 指数发散，不可归一化。唯一的活路是级数在某一阶**截断**：存在 $j = n_r$ 使分子为零，

$$\lambda = n_r + l + 1 \equiv n, \qquad n_r = 0, 1, 2, \dots$$

截断不是技巧性巧合，而是束缚态的**存在条件**：波函数必须在原点温和、在无穷远衰减，两头夹击只放行离散的 $\lambda$ 值。立即得到三条结果：

$$\kappa = \frac{Z}{na_0}, \qquad E_n = -\frac{\hbar^2\kappa^2}{2m_e} = -\frac{Z^2\hbar^2}{2m_e a_0^2 n^2} = -\frac{Z^2\,13.6\ \text{eV}}{n^2}, \qquad n \ge l + 1,$$

最后一条就是 $n = n_r + l + 1$ 的直接读法（$n_r \ge 0$）。**主量子数 $n$ 是径向驻波的计数**：$n_r = n - l - 1$ 恰是径向波函数的节点数，截断多项式就是连带 Laguerre 多项式 $L_{n-l-1}^{2l+1}$。基态自查：$n = 1$ 迫使 $l = 0$、$n_r = 0$，$\psi_{100} \propto e^{-Zr/a_0}$——无节点、无角结构，全对上。

用 $\alpha$ 改写 $E_1 = -m_ec^2\alpha^2/2 \approx -13.6$ eV：能标是电子静止能乘 $\alpha^2$——原子物理天生是非相对论性的（$\alpha$ 小），相对论修正（精细结构 $\sim \alpha^4$）留给第 03 篇微扰论与 stage-03 的 Dirac 方程。

### 2.3 账本：$n^2$、$2n^2$ 与 s/p/d/f

固定 $n$，允许 $l = 0, \dots, n-1$，每个 $l$ 有 $2l+1$ 个 $m$。计数：

$$\sum_{l=0}^{n-1}(2l+1) = n^2 \quad\xrightarrow{\ \times 2\ (\text{自旋})\ }\ 2n^2.$$

这组简并的**来源并不平等**，记账要分开（第 02 篇第 8 节从对称性说过，这里从解的结构再看一遍）：

- **$m$ 简并**：任何中心势都有（旋转对称性的必然），最不金贵——加磁场（Zeeman）就拆掉；
- **$l$ 简并**：库仑势特供，来自隐藏的 SO(4) 对称性（Laplace–Runge–Lenz 矢量 $\vec A = \tfrac{1}{2m_e}(\vec p\times\vec L - \vec L\times\vec p) - Ze^2\vec r/4\pi\varepsilon_0 r$ 与 $H$ 对易，与 $\vec L$ 一起生成 so(4)）。势场稍偏离 $1/r$ 就消失——这正是下一节的主角；
- **自旋因子 2**：与势场无关，是电子的内禀自由度。

命名法（一句话来历，详见自检问题 5）：$l = 0,1,2,3$ 叫 s、p、d、f，名字来自碱金属光谱的四条谱线系（sharp、principal、diffuse、fundamental）的首字母；$n = 1,2,3,\dots$ 的壳层叫 K、L、M……来自 X 射线谱。化学写法 $3d$ = 第 3 壳层（$n=3$）的 $l=2$ 亚层。形状一句话：$l=0$ 球对称，$l=1$ 沿轴双瓣，$l$ 越大角向结构越复杂（$Y_l^m$ 的节点数 = $l$）。

## 3. 多电子原子：亚层次序从哪来

氢原子里 $E$ 只依赖 $n$，"亚层"只是简并的记账；**多电子原子里 $E$ 变成 $(n,l)$ 的函数，亚层才有了独立身份**。

### 3.1 Pauli 原理：座位表

电子是费米子，总波函数反对称（交换起源的推导见凝聚态书[磁性](../../../condensed-matter/docs/07-magnetism.md)第 2 节），推出 Pauli 不相容原理：**两个电子不能共享同一组 $(n, l, m_l, m_s)$**。于是每个亚层（固定 $n, l$）有

$$2(2l+1) \quad \text{个座位} \qquad (2l+1 \text{ 个 } m_l \times 2 \text{ 个自旋}),$$

每壳层 $\sum_l 2(2l+1) = 2n^2$。填充从低能到高能逐格进行——剩下的问题只有一个：**能量次序是什么？**

### 3.2 屏蔽与钻穿：$E$ 从 $n$ 变成 $(n, l)$

氢原子只有一个电子，看到的是全部核电荷 $+Ze$。多电子原子中，外层电子看到的有效电荷被内层电子屏蔽成 $Z_{\text{eff}}(r) < Z$，能量近似按类氢公式估算：

$$E \sim -13.6\ \text{eV}\times\frac{Z_{\text{eff}}^2}{n^2}.$$

若屏蔽是"完全"的（$Z_{\text{eff}} = Z - \text{内层电子数} = 1$），能量回到只依赖 $n$，亚层简并复原。但屏蔽永远不完全，且**不完全的程度强烈依赖 $l$**——第 2.1 节的离心垒图像现在收账：

- **s 态（$l=0$）无离心垒**：径向波函数在核区有可观概率（还带内节点、内瓣），深深**钻穿**（penetration）进内层电子云，在 $r$ 小处感受到接近裸的 $Z$，强吸引大幅拉低能量；
- **d/f 态离心垒高**：波函数被推到内层电子云之外，屏蔽得很干净，$Z_{\text{eff}}$ 小、能量高。

于是同一 $n$ 内部裂开：$E(ns) < E(np) < E(nd) < E(nf)$；不同 $n$ 之间也可以倒挂——最著名的一例：钾（$Z=19$）的 4s 钻穿足够深，反而沉到 3d 之下：

$$E(4s) < E(3d) \qquad (Z = 19, 20\ \text{时}),$$

所以第 19、20 个电子先填 4s（K 是 $[\text{Ar}]4s^1$、Ca 是 $[\text{Ar}]4s^2$），第 21 个才进 3d——周期表从此进入过渡金属区。反转也会发生：3d 一旦开始填充，本身收缩、能量下沉到 4s 之下，并反过来屏蔽 4s——**这就是过渡金属成键/电离时先丢 4s 电子的原因**（自检问题 4）。

### 3.3 Madelung 规则与周期表的分区

把屏蔽+钻穿的效果总结成经验排序（Madelung $n+l$ 规则：先填 $n+l$ 小的，$n+l$ 相同先填 $n$ 小的）：

$$1s\ 2s\ 2p\ 3s\ 3p\ \mathbf{4s\ 3d}\ 4p\ \mathbf{5s\ 4d}\ 5p\ \mathbf{6s\ 4f\ 5d}\ 6p\ \mathbf{7s\ 5f\ 6d}\ 7p$$

加粗处就是倒挂。周期表的分区全部由亚层决定：s 区（碱金属碱土）、p 区（主族）、d 区（过渡金属）、f 区（镧系锕系）。两条著名的例外都是"半满/全满更稳"（Hund 交换能的功劳，凝聚态书[为什么铁有磁性](../../../condensed-matter/docs/07s-why-iron-magnetic.md)里有 Hund 定则的完整推导）：

$$\text{Cr：}\ [\text{Ar}]3d^54s^1\ \text{而非}\ 3d^44s^2, \qquad \text{Cu：}\ [\text{Ar}]3d^{10}4s^1\ \text{而非}\ 3d^94s^2.$$

铁按常规填：$[\text{Ar}]\,3d^64s^2$——3d 亚层 10 座坐 6 人，5 上 1 下，自旋 $S = 2$。这句组态正是凝聚态磁性笔记的出发语言。

## 4. 接口：这套记账往后通到哪里

- **微扰论（第 03 篇）**：氢原子的 $n^2$ 简并使外场微扰大有可为——电场下不同 $l$（相反宇称）直接混杂，线性 Stark 效应只有在 $l$ 简并时才存在（第 03 篇 4.3 节正是这个例子）；磁场拆 $m$ 简并给 Zeeman。简并微扰论的全部技巧都在这个 $n^2$ 维子空间里操练。
- **相对论（stage-03 的 Dirac 方程）**：精细结构修正 $E_{nj} \sim \alpha^4$，能级从只依赖 $n$ 变成依赖 $(n, j)$——Dirac 方程自动给出。更深一层，Dirac 预言的 $(n,j)$ 内简并被 Lamb 位移拆掉（$\sim\alpha^5$），那是 QED 的第一场精度表演（stage-04）。**氢原子的简并账本是通往量子电动力学的台阶**：每破一层对称，理论就前进一个时代。
- **凝聚态书**：亚层 → 能带——3d 窄带、4s 宽带的差异（[能带论](../../../condensed-matter/docs/04-band-theory.md)第 7 节贵金属一段）、未满 d 壳层的磁性与 Stoner 判据（[为什么铁有磁性而铜、铝没有](../../../condensed-matter/docs/07s-why-iron-magnetic.md)）、Mott 物理与超交换（[强关联浅尝](../../../condensed-matter/docs/13-strong-correlations.md)）全踩在本篇的填充语言上。
- **化学**：元素周期表是量子力学交出的第一份成绩单——周期 = 最外层填充的重启，族 = 最外亚层组态，过渡金属插入 = 3d 倒挂，镧系收缩 = 4f 深藏。本篇就是那张成绩单的推导过程。

## 小结

- 量子数分工表：

| 量子数 | 来历 | 取值 | 管什么 |
| --- | --- | --- | --- |
| $n$ | 径向方程级数截断，$n = n_r + l + 1$ | $1, 2, \dots$ | 能级（氢）、壳层容量 $2n^2$、径向节点数 |
| $l$ | 角向 SO(3) 表示（球谐函数） | $0, \dots, n-1$ | 亚层（s/p/d/f）、形状、离心垒 → 钻穿能力 |
| $m_l$ | $L_z$ 本征值 | $-l, \dots, l$ | 取向简并（Zeeman 拆） |
| $m_s$ | 自旋 | $\pm\tfrac12$ | 座位 ×2、磁性种子 |

- 氢：$E_n = -Z^2\,13.6\ \text{eV}/n^2$，简并 $n^2$（$m$ 简并人人有份，$l$ 简并是库仑 SO(4) 特供）。
- 多电子：屏蔽拆掉 $l$ 简并，钻穿使 $E = E(n, l)$，倒挂 4s/3d 造就过渡金属；Madelung $n+l$ 规则排周期表；Cr/Cu 例外是 Hund 交换。
- 亚层容量 $2(2l+1)$，壳层 $2n^2$；过渡金属先电离 4s。

## 自检问题

**1.** 从径向方程出发，完整推导截断条件 $n = n_r + l + 1$ 与能级公式 $E_n = -Z^2\hbar^2/(2m_ea_0^2n^2)$，并说明为什么截断是束缚态的存在条件而非数学巧合。

<details markdown="1"><summary>点击显示答案</summary>

束缚态 $E<0$，令 $\kappa = \sqrt{-2m_eE}/\hbar$，$\rho = 2\kappa r$，$\lambda = Z/(\kappa a_0)$，代入 $u(\rho) = \rho^{l+1}e^{-\rho/2}v(\rho)$（渐近行为：原点离心垒给 $\rho^{l+1}$，无穷远给 $e^{-\rho/2}$），得

$$\rho v'' + (2l+2-\rho)v' + (\lambda - l - 1)v = 0.$$

设 $v = \sum_{j=0}^\infty a_j\rho^j$，比较 $\rho^{j+1}$ 系数得递推

$$a_{j+1} = \frac{j + l + 1 - \lambda}{(j+1)(j + 2l + 2)}\,a_j.$$

**发散论证**：若级数不截断，大 $j$ 时 $a_{j+1}/a_j \to 1/j$，与 $e^{+\rho} = \sum \rho^j/j!$ 的系数比相同，故 $v \sim e^{+\rho}$，$u \sim \rho^{l+1}e^{+\rho/2}$ 在无穷远爆炸，不可归一化——这样的"解"根本不是态矢量。

**截断条件**：唯一的出路是分子在某个 $j = n_r \ge 0$ 处归零，此后 $a_{j>n_r} = 0$，$v$ 退化为 $n_r$ 次多项式（即 $L_{n_r}^{2l+1}$）。归零要求

$$\lambda = n_r + l + 1 \equiv n \;\Longrightarrow\; \kappa = \frac{Z}{na_0}.$$

代回 $E = -\hbar^2\kappa^2/2m_e$：

$$E_n = -\frac{Z^2\hbar^2}{2m_ea_0^2n^2} = -\frac{Z^2\,13.6\ \text{eV}}{n^2} = -\frac{Z^2 m_ec^2\alpha^2}{2n^2}.$$

**为什么是存在条件**：方程本身对任意 $E$ 都有形式解，但物理态必须是希尔伯特空间里的归一化矢量——两端边界条件（原点温和、无穷远平方可积）把连续的 $E$ 压成离散谱，截断就是边界条件的代数化身。$n \ge l+1$（因 $n_r \ge 0$）、$n_r = n - l - 1$ 个径向节点，都是同一条件的读法。

</details>

**2.** 数清氢原子的简并账本：证明第 $n$ 壳层（不含自旋）简并度为 $n^2$、含自旋为 $2n^2$；并指出各级简并分别由什么对称性保证、各被什么外场拆掉，氢的线性 Stark 效应为什么成立而碱金属没有。

<details markdown="1"><summary>点击显示答案</summary>

**计数**：

$$\sum_{l=0}^{n-1}(2l+1) = \sum_{l=0}^{n-1}\big[1 + 2l\big] = n + 2\cdot\frac{(n-1)n}{2} = n^2,$$

自旋使每个轨道态翻倍：$2n^2$。

**对称性记账**：

- $m$ 简并（$2l+1$ 重）：中心势的 SO(3) 旋转对称性——任何球对称 $V(r)$ 都有，最廉价。磁场 $B_z$ 加入 $H' \propto L_z$ 后 $m$ 不再简并，谱线按 $\Delta m = 0,\pm1$ 分裂（正常 Zeeman）。
- $l$ 简并（固定 $n$ 内）：库仑 $1/r$ 特有的隐藏 SO(4)（Runge–Lenz 矢量守恒）。势偏离 $1/r$ 即破缺——碱金属的核芯电子云使等效势不再是纯 $1/r$，$ns/np/nd$ 当即裂开。
- 自旋 ×2：电子内禀自由度，任何外场都在，只能被自旋选择定则"选用"而非拆除。

**Stark 的对比**：均匀电场的微扰 $e\mathcal E z\propto rY_1^0$ 是宇称奇的，只能耦合宇称相反的态。氢的 $n^2$ 维简并子空间里**同时含有相反宇称的 $l$**（$(-1)^l$），一阶能量修正非零——线性 Stark 效应（第 03 篇 4.3 节的简并微扰论范例）。碱金属的 $l$ 简并已被核芯屏蔽提前拆掉，简并子空间内没有相反宇称伙伴，一阶为零，只有二阶（平方）Stark 效应。**简并度决定微扰论的"起点难度"——这正是第 03 篇要专门处理简并微扰的原因。**

</details>

**3.** 用电离能反推有效电荷：Na（$3s$，$I_1 = 5.14$ eV）与 K（$4s$，$I_1 = 4.34$ eV）。计算两者的 $Z_{\text{eff}}$，说明为什么它们都显著大于"完全屏蔽"给出的 1，以及哪个的钻穿相对更厉害。

<details markdown="1"><summary>点击显示答案</summary>

**反推**：类氢关系 $E = -13.6\,Z_{\text{eff}}^2/n^2$，故 $Z_{\text{eff}} = n\sqrt{I_1/13.6\ \text{eV}}$：

$$\text{Na}(n=3):\quad Z_{\text{eff}} = 3\sqrt{5.14/13.6} = 3\times0.615 \approx 1.85,$$

$$\text{K}(n=4):\quad Z_{\text{eff}} = 4\sqrt{4.34/13.6} = 4\times0.565 \approx 2.26.$$

**对照完全屏蔽**：若内层电子把核电荷挡干净，价电子只看到 $Z_{\text{eff}} = 1$，则 Na 应为 $13.6/9 = 1.51$ eV、K 应为 $13.6/16 = 0.85$ eV——实验值分别是它们的 3.4 倍和 5.1 倍。结论：价电子云显著穿透内层（s 态无离心垒 + 内瓣直达核区），在小 $r$ 处看到远多于 1 份电荷。

**谁钻得更凶**：偏离完全屏蔽的倍数 K（5.1 倍）大于 Na（3.4 倍），且 K 的 $Z_{\text{eff}} = 2.26 > 1.85$——4s 虽然主量子数更大，但径向函数内节点更多、内瓣更深，加上 K 的核芯（Ar）更大更松散，穿透收益反而更高。这正是 3.2 节 $E(4s) < E(3d)$ 倒挂的定量证据：倒挂不是 4s"整体"更低，而是它的**核区瓣**足够低，把期望值拉了下去。

</details>

**4.** 用 Madelung 规则排出 K（$Z=19$）到 Zn（$Z=30$）的基态组态，标出例外元素并解释；写出 Fe 与 Fe$^{2+}$ 的组态并说明为什么电离先丢 4s。

<details markdown="1"><summary>点击显示答案</summary>

Ar 核心（18 电子）之后按 $4s \to 3d$ 排：

| 元素 | 组态 | 备注 |
| --- | --- | --- |
| K、Ca | $[\text{Ar}]4s^1$、$[\text{Ar}]4s^2$ | 4s 在 3d 之下（钻穿倒挂） |
| Sc–V | $[\text{Ar}]3d^14s^2$ … $3d^34s^2$ | 常规 |
| Cr | $[\text{Ar}]3d^54s^1$ | 例外：半满 $d^5$ |
| Mn–Ni | $3d^54s^2$ … $3d^84s^2$ | 常规 |
| Cu | $[\text{Ar}]3d^{10}4s^1$ | 例外：全满 $d^{10}$ |
| Zn | $[\text{Ar}]3d^{10}4s^2$ | 常规 |

**例外的原因**：半满（$d^5$）与全满（$d^{10}$）亚层有额外的稳定性——半满时 5 个电子平行自旋各占一条 $m_l$ 轨道，交换能收益最大（Hund 第一定则，微观是库仑 + Pauli，凝聚态书[磁性](../../../condensed-matter/docs/07-magnetism.md)第 2 节推导）。Cr 把一个 4s 电子搬进 3d 换取 $d^5$、Cu 换取 $d^{10}$，说明这里能量差已经小到"一电子级"——亚层次序本来就是对屏蔽细节敏感的近似。

**Fe 与电离**：Fe 基态 $[\text{Ar}]3d^64s^2$（3d 六座：5 上 1 下，$S = 2$）。电离先丢 4s：3d 填充开始后，$d$ 电子云收缩、自身能量沉到 4s 之下，且 $d^{n}$ 电子位于内层、把 4s 屏蔽得更彻底，净效果 $E(3d) < E(4s)$（对已填充的过渡金属）。故 Fe$^{2+}$ 是 $[\text{Ar}]3d^6$，而不是 $3d^44s^2$——过渡金属化学价态的组态都遵循"先丢 s"。

</details>

**5.** 钠的双黄 D 线（589 nm，约 2.10 eV）是 $3p \to 3s$ 跃迁。同样的 $n = 3$，氢不分裂而钠裂开约 2.1 eV——为什么？由数据反推 $Z_{\text{eff}}(3s)$ 与 $Z_{\text{eff}}(3p)$，并讲讲 s/p/d/f 名字与这条谱线的渊源。

<details markdown="1"><summary>点击显示答案</summary>

**为什么裂**：氢的 $l$ 简并由库仑 $1/r$ 的 SO(4) 保证，$3s$ 与 $3p$ 严格同能。钠有 10 个核芯电子（$1s^22s^22p^6$），价电子看到的是被屏蔽的等效势——不再是纯 $1/r$，SO(4) 破缺，$E$ 变成 $E(n,l)$：$3s$ 钻穿越深、能量越低，$3p$ 离心垒较高、屏蔽更干净，两者裂开。这正是"亚层"脱离"壳层"获得独立身份的实验现场。

**反推**：$E(3s) = -I_1 = -5.14$ eV；$E(3p) = -5.14 + 2.10 = -3.04$ eV。由 $E = -13.6\,Z_{\text{eff}}^2/9$：

$$Z_{\text{eff}}(3s) = 3\sqrt{5.14/13.6} \approx 1.85, \qquad Z_{\text{eff}}(3p) = 3\sqrt{3.04/13.6} \approx 1.42.$$

同一壳层内两个亚层的有效电荷差 0.43——这就是"钻穿差"的定量大小。（双线本身再裂 0.002 eV 成 D₁/D₂，那是 $3p$ 的自旋轨道耦合劈裂 $^2P_{3/2,1/2}$，第 02 篇第 6 节角动量相加的主场。）

**命名渊源**：碱金属光谱在 19 世纪被整理成四条线系——sharp（锐线系，到 s 态的跃迁）、principal（主线系，到 p 态，D 线属于它、强度最大）、diffuse（漫线系，到 d 态）、fundamental（基线系，到 f 态）。量子力学解出 $l$ 之后，人们把四条线系的末态 $l = 0,1,2,3$ 依次命名为 s、p、d、f——**先有谱线系的名字，后有量子数的名字**；亚层记号本身就是量子力学"认领"光谱学遗产的现场。

</details>
